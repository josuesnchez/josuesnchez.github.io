# ICAS Ltda. — Tarjeta digital (destino del QR)

Sitio estático de una sola página. No requiere build ni dependencias.

## Publicar en GitHub Pages
1. Crea un repositorio (ej. `icas-tarjeta-digital`) y sube **todo el contenido de esta carpeta** a la raíz.
2. Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / carpeta `/ (root)`.
3. La página queda en `https://<usuario>.github.io/<repositorio>/`.
4. Genera tu QR apuntando a esa URL (o a tu dominio, ej. `qr.icasltda.com`).

## Brochure
El botón "Ver nuestro Brochure" apunta a `brochure/ICAS-Brochure.pdf`.
Sube tu PDF con ese nombre exacto dentro de la carpeta `brochure/` del repositorio.
Si prefieres un enlace externo (Drive, web), edita el `href` de ese botón en `index.html`.
